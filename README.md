# cyber-journal

My cybersecurity learning path, documented as I go.

I come from low-level C projects at 42 and I'm building my security skills through hands-on practice: labs, challenges and small projects. This repository holds what I do each week, including what went wrong.

## Current focus

**Phase 0: Foundations**

- Networking review: DNS, NAT and the OSI and TCP/IP models
- Setting up a Raspberry Pi as a home lab, with security checks

## How it works

- Work is split into phases, each with its own goals.
- Each week ends with a published deliverable.
- I focus on practical work first and look up the theory I need along the way.

## Ground rules

- Everything here is for learning.
- I only test systems I own or have explicit permission to test.
- Write-ups follow each platform's rules, so active challenges are not published.
- Personal details, such as real IP addresses and credentials, are left out or redacted.
